# Scalable-Web-App-with-NLB-and-Auto-Scaling
Scalable web app using EC2, Network Load Balancer (NLB), and Auto Scaling to handle high-performance, low-latency traffic with high availability.

## 🎯 Purpose
Handle very high-performance and low-latency traffic.

## 🧰 AWS Services Used
- Amazon EC2
- Network Load Balancer (NLB)
- Auto Scaling

## 📌 Project Overview
This project demonstrates a high-performance web application on AWS. 
Network Load Balancer ensures low latency, while Auto Scaling automatically adjusts EC2 instances based on traffic.

## 🚀 Features
- Low-latency traffic handling
- High performance
- Automatic scaling
- High availability
